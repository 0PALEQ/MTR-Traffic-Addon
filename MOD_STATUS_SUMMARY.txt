Current feature status
======================

- Spawn/despawn connectors create traffic routes over MTR rail geometry and store per-spawn vehicle pools, intervals, names, directions, enabled state, and materialization limits.
- Traffic runs on a dedicated 50 ms wall-clock simulation loop with deterministic virtual departures, distance-based materialization, spacing and congestion handling, and asynchronous per-player network filtering.
- The localized responsive dashboard supports connector/intersection search, inline connector renaming, Locate/Pool row actions, vehicle-pool copy/paste, map fitting/caching, and Crossing/Train intersection levels.
- Manual and automatic road intersections, node/group traffic-light bindings, pedestrian clearance blinking, train detection, tollgate poles, and animated tollgate bars are implemented.
- The MTR Path Blocker Connector toggles a marker on an existing rail so new MTR siding/depot path searches omit that segment while preserving the rail's other properties.
- The Universal Road Sign supports resource-pack bases, four Unicode text lines, text/background/edge colors, custom dimensions, imported PNG artwork, server-side validation, and world-backed multiplayer image synchronization.
- Built-in vehicle resources include sedans, taxi, hatchbacks, and five Nissan Sentra colors.
- All 13 registered addon items have crafting recipes and recipe-book unlock advancements.
- Included languages are English, Polish, German, Japanese, French, Spanish, Czech, and Simplified Chinese.

Known notes and remaining work
==============================

- Back up world data before upgrading and regenerate affected MTR depot routes after toggling a path blocker.
- The removed MTA-exclusive 20-120 speed connector items are no longer registered; spawn/despawn connectors and the MTR Path Blocker Connector are the supported tools.
- Large-network behavior should continue to be tested with multiple players and long route networks.
- Automatic and Train intersections depend on recent graph and vehicle observations near players and intentionally fail open when state is stale or remote.
- Spawn density controls remain based on spawn interval and maxVehicles; dashboard controls for maxVehicles are not exposed.
- Traffic quality depends on the underlying MTR rail graph, and fallback graph requests cover 8192 blocks around a player.
- Custom traffic-model support currently focuses on OBJ resources.
- Unused imported road-sign PNGs remain stored with the world and are not garbage-collected automatically.
